# Deterministic photo fixtures

These files are synthetic, tiny, and contain no user or location data. Regenerate them with:

```powershell
npm run fixtures:generate
```

`orientation-1.jpg` through `orientation-8.jpg` share the same pixels and carry one EXIF
orientation value each. `sample.png` is a 4×3 RGBA PNG with deterministic colours and no metadata.
The generator is idempotent and rewrites a file only when its generated bytes differ.

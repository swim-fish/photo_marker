# Photo Marker v1.0.0

First stable release of Photo Marker, a mobile-friendly photo annotation PWA.

- Import photos with GPS metadata or choose a location manually, on a map, or
  using device location.
- Display WGS84, TWD97, and MGRS coordinates with semantic wrapping and grid
  precision descriptions.
- Add corner text, RGBA backgrounds, and single or repeated watermarks.
- Reuse templates with default text and watermark settings.
- Export annotated photos and recover or discard local drafts.
- Install the app for offline editing after initial resource preparation.
- Deploy published stable releases to GitHub Pages and display the release
  version in the app footer.

Online maps require network access. Device location requires permission.
Photos and drafts stay on the device; clearing site data removes saved drafts
and templates.

App: https://swim-fish.github.io/photo_marker/

# Photo Marker v1.0.1

Improve Android photo import when the system photo picker removes GPS metadata.

- Request general file selection on Android and add an explicit original-file
  picker on the welcome page and when no photo GPS is read.
- Explain how to select the original JPEG or PNG from DCIM/Camera and include
  location if the system picker offers that option.
- Accept empty or generic document-provider MIME types only after validating
  actual JPEG/PNG contents; preserve original photo bytes and GPS metadata.
- Allow selecting the same filename again and avoid claiming the original photo
  has no GPS when the selected copy does not contain it.

Validated with 254 unit/component/integration tests and four mobile/desktop
browser journeys covering GPS import and Pages offline startup.

Android 16 / Samsung One UI 8.5 native picker behavior still requires device
verification. Browser tests do not emulate Android's native photo or document
providers. A PWA cannot restore GPS metadata already removed by the provider.

App: https://swim-fish.github.io/photo_marker/
